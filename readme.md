# Java Algorithms — 6 задач

## Описание проекта

Проект содержит решения шести алгоритмических задач на языке Java.

Все решения находятся в одном файле `Main.java`.

## Требования

- Java JDK 17 или новее.
- Windows, Linux или macOS.
- Терминал или командная строка.

## Структура проекта

```text
alg/
├── Main.java
└── README.md
```

## Как запустить проект

### 1. Откройте папку проекта

Откройте командную строку (CMD) и перейдите в папку проекта:

```cmd
cd C:\Users\ameti\Desktop\alg
```

### 2. Выберите задачу

Откройте файл `Main.java` и найдите метод `main()`:

```java
public static void main(String[] args) throws Exception {
    solve1();
}
```

Для запуска нужной задачи укажите соответствующий метод:

| Задача | Метод |
|---|---|
| Задача 1 | `solve1();` |
| Задача 2 | `solve2();` |
| Задача 3 | `solve3();` |
| Задача 4 | `solve4();` |
| Задача 5 | `solve5();` |
| Задача 6 | `solve6();` |

**Важно:** одновременно запускается только одна задача, поскольку у каждой задачи свой формат входных данных.

### 3. Запустите программу

В командной строке выполните:

```cmd
java Main.java
```

### 4. Введите входные данные

Пример входных данных для задачи 2:

```text
3 8
2 3
3 4
4 5
```

После ввода данных нажмите `Ctrl + Z`, затем `Enter`, чтобы завершить ввод в Windows CMD.

Ожидаемый результат:

```text
9
```

## Запуск с помощью файла input.txt

Вместо ручного ввода можно создать файл `input.txt` с тестовыми данными.

Пример содержимого:

```text
3 8
2 3
3 4
4 5
```

Запуск программы:

```cmd
java Main.java < input.txt
```

## Описание задач

1. **Минимальная стоимость пути** — динамическое программирование.
2. **Задача о рюкзаке 0/1** — максимизация полезности при ограничении массы.
3. **Наибольшая общая подпоследовательность** — динамическое программирование.
4. **Неограниченный рюкзак** — максимизация прибыли и минимизация количества грузов.
5. **Наибольшая возрастающая подпоследовательность** — дерево Фенвика и координатное сжатие.
6. **Кратчайшая общая надстрока** — динамическое программирование и лексикографическая минимизация.

## Примечания

- Все решения написаны на Java.
- Для больших чисел используется тип `long`.
- В задаче 5 количество последовательностей вычисляется по модулю `1 000 000 007`.
- Для каждой задачи предусмотрен отдельный метод `solveN()`.
